# Mobile UI improvements

Review the mobile user interface of the specified screen and every screen nested within it. This is a review and design-sample exercise only; do not implement UI changes yet.

## Review and samples

1. Inspect the specified screen and all its nested screens to understand their existing content, navigation, and user flows.
2. Create five visual UI samples for each screen.
3. Review and analyze the samples against the criteria below, then present all five options for each screen so I can choose the best.

## Design criteria

- **Uniformity:** Keep shared components, styling, and navigation patterns consistent across the proposed screens and samples.
- **Simplicity:** Keep each screen clear and straightforward to use.
- **Accessibility:** Make the interface and its actions easy to access and use.
- **Easy navigation:** Make movement between screens simple and clear.
- **Short flows:** Let users complete each task in as few steps as possible while keeping the flow simple.

Base the samples on the existing screens and content. Do not invent content or add features outside this scope.
