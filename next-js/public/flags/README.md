Local 4:3 SVG country flags from [flag-icons](https://github.com/lipis/flag-icons), used by football country labels and the phone country picker. Flags are MIT licensed; see [LICENSE](LICENSE).

The phone country coverage additions use [flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/fe15c16e7463d0c66d6c5730e9d0e832438d98e1/flags/4x3), pinned to commit `fe15c16e7463d0c66d6c5730e9d0e832438d98e1`. Dialing regions AC and TA use the upstream `sh-ac` and `sh-ta` flags. World and unknown countries retain the globe fallback.
