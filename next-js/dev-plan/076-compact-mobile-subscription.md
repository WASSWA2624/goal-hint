# 076 Compact mobile subscription status

Fit the active subscription's date, year, time, EAT and remaining duration on one
phone line using compact wording, a 16px icon, tighter spacing and readable
11–12px type. Retain full wording for assistive technology and wider screens.
Allow natural wrapping when text is enlarged; preserve payment/renewal notices.

Verify actual line fit at 320/360/375/414 px in both themes, both header layouts
and both duration formats, plus tablet/desktop and enlarged-text behavior.
