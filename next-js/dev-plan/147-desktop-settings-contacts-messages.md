# 147 · Desktop settings, support contacts and message templates

## Scope

Implement the approved desktop Settings workspace with a compact title/tab row,
full-width content and a visible save footer. Preserve the existing mobile layout,
four mobile tabs and mobile save actions. Keep all shared logic in `next-js/`.
Keep the MTN and Airtel dial-code inputs visible on desktop, outside collapsible
sections, as requested in the follow-up.

## Implementation

- Provide editable support contacts with network labels, call/WhatsApp methods,
  enable/primary controls and add/remove actions. Existing configured numbers
  remain the fallback until an explicit contact list is saved. Project primary
  contacts to the legacy fields so existing mobile support stays compatible.
- Explain access modes as subscriptions closed, testing and subscriptions open.
  Keep existing entitlement rules, confirmation and launch requirements intact.
- Clarify copied number format, payment review estimates and payment instructions.
- Add validated event/channel message templates, an insertion picker describing
  variable sources and sample previews. Verification codes remain generated by
  authentication; settings store templates only. Keep provider credentials private.
- Connect configured templates to real verification and payment notification
  paths. Use approved WhatsApp template parameters and independent durable
  channel claims; display email as unavailable pending an email integration.
- Add nullable settings columns and a backward-compatible notification migration.
  Never send real messages from automated verification.
